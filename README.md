# homework_10_1

## Описание:

Цель проекта - реализовать функции, возвращающие список словарей и сортирующие их.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте main.py в src для проверки новых функций

## Новый модуль: generators.py

### Модуль generators.py содержит функции, реализующие генераторы для обработки данных:

1. filter_by_currency - функция возвращает итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной.
2. transaction_descriptions - функция возвращает описание каждой транзакции.
3. card_number_generator - генерирует номера карт


## Тестирование

Чтобы запустить тесты, выполните команду:

```bash
pytest
```
### Тесты test_masks.py проверяют:
1. Правильность маскирования карты/счета
2. Как функция реагирует на неправильную длину и лишние символы 

### Тесты test_widget.py проверяют:
1. Что функция корректно распознает и применяет нужный тип маскировки в зависимости от типа входных данных (карта или счет).
2. Как функция реагирует на некорректный ввод данных
3. Правильность преобразования даты в различных входных форматах
4. Не падает при некорректном вводе данных

### Тесты test_processing.py проверяют:
1. Фильтрацию списка словарей по заданному статусу
2. Работу функции при отсутствии словарей с указанным статусом
3. Параметризацию тестов для различных возможных значений статуса
4. Сортировку списка словарей по датам в порядке убывания и возрастания
5. Корректность сортировки при одинаковых датах
6. Работу функции с некорректными или нестандартными форматами дат

### Измерение покрытия кода:

*Установите плагин:*

```bash
pip install pytest-cov
```
Запустите тесты с измерением покрытия:

```bash
pytest --cov=myapp tests/
```
